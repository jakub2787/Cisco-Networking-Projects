# 🔐 VPN Configuration – GRE Tunnels & RIP Routing

## 📌 Project Overview

This project demonstrates the configuration of GRE (Generic Routing Encapsulation) tunnels in a multi-router network using Cisco Packet Tracer.

GRE tunnels establish logical point-to-point connections between remote routers over an existing IP infrastructure.

RIP version 2 is used as a dynamic routing protocol to exchange routing information between routers and enable communication across remote networks.
