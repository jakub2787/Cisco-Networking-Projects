# 🌐 VLAN Configuration – Cisco Packet Tracer

## 📌 Project Overview

This project demonstrates the configuration of Virtual Local Area Networks (VLANs) in a Cisco switched network using Cisco Packet Tracer.

The main objective is to logically segment a local network into separate broadcast domains, improve network organization and configure switch management.

## 🛠️ Technologies & Concepts

- VLAN (Virtual Local Area Network)
- Cisco Packet Tracer
- Access Ports
- Switch Virtual Interface (SVI)
- IPv4 Addressing
- Network Connectivity Testing
- Trunk Ports
- Access Ports

## ⚙️ Implemented Configuration
- Creation and configuration of VLANs
- Assignment of switch ports to specific VLANs
- Configuration of access ports
- Configuration of a management VLAN
- Switch Virtual Interface (SVI) configuration
- IPv4 addressing and subnet configuration
- Verification of VLAN assignments and connectivity
