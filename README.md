# 🌐 Cisco Networking Projects

A collection of networking projects developed using Cisco Packet Tracer.

This repository contains practical implementations of networking concepts, including switching, VLAN segmentation, routing protocols, VPN tunneling and network security.

Each project includes a Packet Tracer file, network topology, IP addressing documentation and configuration screenshots.

## 📁 Projects

### 1.  VLAN-Configuration
Logical network segmentation and switch configuration.

Documentation includes:

-Network topology
- IP addressing documentation (XLSX / PDF)
- VLAN configuration
- Trunk configuration
- Connectivity tests

### 2.  VPN-GRE-RIP
GRE tunnel configuration and dynamic routing between remote networks.

Documentation includes:
- Network topology
- IP addressing documentation (XLSX / PDF)
- Routing tables
- GRE tunnel status
- Connectivity tests

## 🛠️ Tools & Technologies
- Cisco Packet Tracer
- IPv4 Addressing and Subnetting
- VLAN Configuration
- Static and Dynamic Routing
- RIP and OSPF
- GRE Tunneling
- Trunking
