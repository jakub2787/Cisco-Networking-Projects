## 🌐 Cisco Networking Projects

A collection of networking projects developed using Cisco Packet Tracer.

This repository contains practical implementations of networking concepts, including switching, VLAN segmentation, routing protocols, VPN tunneling and network security.

The projects are designed to demonstrate practical knowledge of Cisco networking technologies, network configuration and troubleshooting.

## 📁 Projects

1.  VLAN-Configuration
2.  VPN-GRE-RIP

## 🛠️ Tools & Technologies
- Cisco Packet Tracer
- IPv4 Addressing and Subnetting
- VLAN Configuration
- Static and Dynamic Routing
- RIP and OSPF
- GRE Tunneling
